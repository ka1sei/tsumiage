# つみあげ — 勉強時間の記録

自分用の勉強時間記録アプリです。
タイマーで勉強時間をはかり、科目ごとに記録して、ごほうびまでの道のりを見られます。

## できること

- タイマー：科目をえらんでスタート、一時停止、終了して記録（メモつき）
- 科目は複数えらべる（時間は等分して記録。内訳はあとから直せる）
- 記録の追加・編集・削除（止め忘れたときに時間を直せる）
- 集計：日・週・月・年・全期間。前の期間にさかのぼれる
- グラフ：日ごと／月ごとの棒グラフ、科目ごとの棒グラフ・円グラフ・表
- 累計時間と、時間に応じたごほうび（全科目の合計、または1科目だけで数える）
- 科目の追加・並べかえ・色の変更・非表示
- スマホとパソコンで同じ記録を見る（Googleスプレッドシートに保存）
- 見る用リンク：ほかの人に、記録とごほうびを見てもらう（合言葉なしで開ける。編集はできない）
  - いま勉強中・一時停止中・勉強していない、の様子も見える（勉強中は経過時間が1秒ずつ進む）

## 開き方

| 目的 | 開くもの |
|---|---|
| 見本のデータで見た目を確かめる | `src/demo.html` をダブルクリック |
| このパソコンだけで使う（ブラウザ版） | `src/index.html` をダブルクリック |
| スマホとパソコンで使う（スプレッドシート版） | `セットアップ手順.md` のとおりに準備（画面は GitHub Pages、保存はスプレッドシート） |
| ほかの人に見てもらう | アプリの「設定」→「見る用リンク」をコピーして送る |

## ファイル

```
study-log/
├─ src/                 アプリ本体（ここを編集する。GitHub Pages に公開される）
│  ├─ index.html
│  ├─ demo.html         見本のデータで開く
│  ├─ manifest.webmanifest  ホーム画面に追加したときの名前と色
│  ├─ icons/            ホーム画面のアイコン（icon.svg が元。PNGは180px・512px）
│  ├─ css/style.css
│  └─ js/
│     ├─ config.js      保存先の設定（Apps Script のURL、見る用の画面に出す名前）
│     ├─ util.js        日付・時間の計算と表示
│     ├─ store.js       保存と同期（ブラウザ版／スプレッドシート版／見るだけ）
│     ├─ charts.js      グラフ（素のHTMLとSVG）
│     └─ app.js         画面とダイアログ
├─ gas/Code.gs          Apps Script に貼り付けるファイル（スプレッドシートへの保存の受付）
├─ .github/workflows/   src を GitHub Pages に公開する設定
├─ tools/build.py       テスト用に Code.gs を複製する
├─ tests/               自動テスト
└─ セットアップ手順.md
```

`src` を直したら、GitHub に push すると、GitHub Pages が自動で新しくなります。
`gas/Code.gs` を直したら、Apps Script に貼りかえて、デプロイを新しいバージョンにします。
テストを開く前に、`python tools/build.py` を実行します（`tests/_code_gs.js` ができます）。

## デザインの決めごと

- 色はエックスサーバーのサイトの配色をもとにした
  - 青 `#0B7BEC`、濃い青 `#004FC8`、水色 `#00A3EC`、文字 `#10181D`、線 `#E6EAED`、背景 `#F3F8FE`
- 青→水色のグラデーションは「計測中」だけに使う（タイマーと、見る用の画面の「いま勉強中」）。色を見れば、はかっている最中だと分かる
  - 見る用の画面の「いまの様子」：勉強中は青→水色、一時停止中はグレー、勉強していないときは白
- 数字は大きく、単位は小さく（Archivo ＋ Zen Kaku Gothic New）
- グラフ
  - 1系列のグラフ（日ごと、科目ごとの棒）は、すべてブランドの青1色
  - 科目の色は「どの科目か」を示すときだけ使う（色の点、円グラフ）
  - 科目の色は、色覚の違いがあっても隣どうしを見分けやすいかを計算で確かめた
  - 円グラフは6つまで。こえた分は「その他」にまとめ、凡例に名前・割合・時間を必ず出す
  - グラフと同じ内容を、表でも見られる
- ロゴは本を積んだ形。名前の「つみあげ」とそろえた
- スマホでは下にメニュー、入力は下から出るシート。パソコンでは左にメニュー

## しくみ

- 素のHTML・CSS・JavaScript（ライブラリなし）
- ブラウザ版：`localStorage` に保存
- スプレッドシート版：画面は GitHub Pages、保存は Google Apps Script のウェブアプリ（`doPost`）が受け付けてスプレッドシートに書く
  - 画面から `fetch` で、変更をまとめて送る（送るのは `text/plain`。事前の確認が要らず、別のサイトからでも送れる）
  - Apps Script は「全員」に公開するので、**合言葉（トークン）**が合わない送信は断る
  - 合言葉は Apps Script のスクリプトプロパティだけに保存する（`setup` を実行すると作られる）。コードやGitには書かない
  - 画面では、端末ごとに1回入れて、その端末の `localStorage` に覚える
  - 変更は端末にためてから、まとめて送る。電波がないときは、つながってから送る
  - 同じデータが2つの端末で変わったときは、あとから変えたほうを残す（削除も同じルール）
  - 1分ごと、また画面に戻ったときに、ほかの端末の変更を取りこむ
- 見る用リンク（`?view=見る用の鍵`）：見るだけの画面になる
  - 見る用の鍵は合言葉とは別。Apps Script のスクリプトプロパティに保存し、持ち主の同期のときに画面へ届ける
  - 見る用の鍵で来た送信は、読むだけで何も保存しない（合言葉がついていても同じ）。スプレッドシートのURLは返さない
  - 読むだけなのでロックは使わず、持ち主の保存を待たせない
  - 画面では、記録とごほうびの2ページだけを出し、編集のボタンは出さない。表示を切りかえる操作だけを受け付ける
  - 見る用の鍵は端末に覚える。`manifest.webmanifest` に `start_url` を書かないのは、ホーム画面に追加したときに `?view=…` つきのURLのまま開くようにするため
  - 見るだけの画面で覚えた記録は、持ち主の記録とは別の場所に置く（同じ端末でも、送っていない変更を消さない）
  - `resetViewKey` で鍵を作り直すと、前のリンクは使えず、見ていた人の画面の記録も消える
  - `?owner` をつけて開くと、覚えた見る用の鍵を忘れて、持ち主の画面に戻る
- 複数の科目をまとめて勉強した記録は、科目ごとの記録に分けて、同じ「まとめID」（groupId）でつなぐ

## テスト

Edge（または Chrome）で次のファイルを開くと、結果が表示されます。

| ファイル | 中身 |
|---|---|
| `tests/test.html` | 日付・集計・グラフの計算、ブラウザ版の保存、Apps Script 側の保存（作り物のスプレッドシートで確認） |
| `tests/gas-sim.html` | スプレッドシート版の同期（ほかの端末の変更、電波がないとき、削除、時計のずれ） |
| `tests/view-sim.html` | 見るだけの画面の同期（届く内容、書きかえられないこと、持ち主の記録にさわらないこと、鍵の作り直し） |
| `tests/e2e.html` | 画面を実際に操作する流れ。`--allow-file-access-from-files` をつけてブラウザを起動して開く |

`tests/test.html`・`tests/gas-sim.html`・`tests/view-sim.html` は、先に `python tools/build.py` を実行しておく必要があります。
